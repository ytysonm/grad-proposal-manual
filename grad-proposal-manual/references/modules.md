# 第 3 步：逐模块开题内容提示词（模块 1-12）

每个模块一段通用提示词，统一要求「分点或分段输出、以高校开题报告格式为准」。将 `{题目}` `{技术栈}` `{场景}` `{功能设计文档要点}` `{参考文献}` 等占位符替换为用户真实内容后，整段复制给 AI 即可。

> 使用前确认：用户已提供 ① 功能设计文档（模块划分、功能点、数据库表）和 ② 按 2.4 分类的知网参考文献。

---

## 模块1 选题背景与意义

核心：为什么做这个题（背景两段式：领域现状→痛点→必要性；意义：理论+实际）

```
我毕设题目是{题目}，技术栈{技术栈}。请基于以下参考文献和功能设计文档，写开题报告「选题背景与意义」：
参考文献：{粘贴文献列表}
功能设计文档要点：{粘贴功能模块/核心功能}
要求：分两段。第一段背景：先写{场景}领域现状，再写当前存在的痛点与不足，最后引出本课题的必要性；第二段意义：写理论意义+实际应用价值。参考以上文献观点但不要照抄原文，语言书面、学术化。
```

---

## 模块2 国内外研究现状

核心：别人做到哪了（国内/国外分线，各 3-5 篇，最后总结不足）

```
基于以下参考文献，写开题报告「国内外研究现状」：
参考文献：{粘贴文献列表}
要求：分「国内研究现状」「国外研究现状」两段。每段概括 3-5 篇代表性文献的研究方向与成果（作者+做了什么+结果），最后一段总结「现有研究的不足与空白」，并说明本课题针对该空白展开。不要逐篇罗列，要按主题归纳。
```

---

## 模块3 文献综述

核心：对文献分类评述，落到「研究空白 = 我的切入点」（只综不述）

```
基于参考文献{粘贴文献列表}，写开题报告「文献综述」：
要求：按{技术/方法/场景}分 2-3 类评述，每类先综述再评价（优点+局限），最后一段总结研究空白，并说明本课题切入点。只综不述、与「研究现状」重复均为不合格。
```

---

## 模块4 研究内容

核心：总目标 + 可量化子目标 + 分点研究内容

```
我的功能设计文档要点：{粘贴功能模块划分}
写开题报告「研究内容」：
要求：先写研究目标（总目标 1 句 + 2-3 个可量化子目标），再分点列出研究内容（结合功能设计文档的功能模块，每点写「做什么+达到什么效果」）。按编号分点输出。
```

---

## 模块5 拟解决的关键问题与难点

核心：2-4 个难点 + 对策（难点 ≠ 创新点）

```
基于题目{题目}、技术栈{技术栈}、功能设计文档{要点}，写「拟解决的关键问题与难点」：
要求：列出 2-4 个关键问题/难点（如数据获取与处理、核心算法精度、并发与性能、安全与权限等，按实际方向选），每个难点写清楚「难在哪里 + 拟采用的解决思路」。分点输出。
```

---

## 模块6 核心创新点

核心：2-3 个，和现有工作比新在哪（不要「用了某框架」当创新）

```
基于题目{题目}和文献综述中的研究空白，写「核心创新点」：
要求：2-3 点即可。可以从{算法/方法改进、应用场景创新、技术组合、功能设计优化}等维度写，每点写清楚「相对现有工作的差异」。不要把「用了某个框架」当创新。
```

---

## 模块7 研究方法与手段

核心：选 2-3 个匹配课题的方法，说明用在哪个环节

```
基于题目{题目}和技术栈{技术栈}，写「研究方法与手段」：
要求：从文献研究法、需求分析法、对比实验法/控制变量法、实证验证法、问卷调查法等中选择 2-3 个与本课题匹配的，每个方法写「在哪个环节用、怎么用」。分点输出。
```

---

## 模块8 技术路线

核心：宏观流程（需求分析→设计→编码→测试→优化→部署）+ 技术选型理由

```
基于技术栈{技术栈}和功能设计文档，写「技术路线」：
要求：按时间顺序写完整流程：需求分析→系统/算法设计→{编码/模型训练}实现→测试→优化→部署上线；说明关键技术选型（{后端}{前端}{数据库}）及选择理由；涉及算法的写明训练-验证-评估环节。分段输出。
```

---

## 模块9 可行性分析

核心：技术/经济/时间/资源四维度

```
基于题目{题目}技术栈{技术栈}，写「可行性分析」：
要求：分四段——技术可行性（技术成熟度与本人掌握程度）、经济可行性（开发成本低，仅需电脑与开源软件）、时间可行性（与进度安排匹配）、资源可行性（数据/设备/指导条件）。每段 2-3 句，落到具体资源。
```

---

## 模块10 实现方案

核心：具体怎么做（架构、模块划分、数据库、关键实现），与「技术路线」不重复

```
基于功能设计文档要点{粘贴内容}和技术栈{技术栈}，写「实现方案」：
要求：写总体架构（{前端}与{后端}交互方式）、功能模块划分（每个模块的职责）、数据库设计（核心表及关系）、关键技术实现细节。分段输出，与「技术路线」不要重复。
```

---

## 模块11 研究进度安排

核心：阶段时间表 + 里程碑交付物

```
我的开题时间是{年月}，预计答辩时间是{年月}。请写「研究进度安排」：
要求：按阶段给出时间表（如：文献调研与开题→需求分析→系统/模型设计→编码实现→测试优化→论文撰写→答辩准备），每个阶段写「时间段+主要任务+阶段成果/交付物」。用编号分点或表格形式。
```

---

## 模块12 预期成果

核心：交付什么 + 可验证指标

```
基于题目{题目}，写「预期成果」：
要求：列出可运行系统/模型、毕业论文、源代码、数据集、软著/专利/论文（可选）等成果，并给出 2-3 个可验证指标（如功能完成度、性能指标、准确率等）。分点输出。
```
